臨床導入・活用・守りに特化

PubMed 全件ではなく、Deployment / Use / Safety の 3 クラスタに絞って収集します。

Governance 7 軸 overlay

出典明示 / ハルシネーション check / 再現性 / disclaimer / 監査ログ / retraction filter / COI 抽出 を 各論文に自動で添えます。読む前に「信頼できるか」が分かる構造です。

自分用、完全に非公開

誰にも読まれない、あなた専用の朝の private briefing。
SaaS ではなくあなたの GitHub Actions で動くので、クエリも閲覧ログも外に出ません。

10 分セットアップ

GitHub template を使って fork、secrets を 3 本貼って config を 1 行編集、以上です。

  1. 1

    GitHub で "Use this template"

    cursorvers/auditscope を自分のアカウントに複製します。private repo 推奨。

  2. 2

    Google AI Studio で Gemini API key を発行

    無料枠で daily digest は十分まわります。key をコピーしておきます。

  3. 3

    Gmail App Password を発行

    2 段階認証 ON → アプリ パスワードを 1 個作成。これが自分宛送信の SMTP 認証に使われます。

  4. 4

    GitHub Secrets に 3 本貼付

    GEMINI_API_KEY / GMAIL_ADDRESS / GMAIL_APP_PASSWORD を repo の Settings > Secrets and variables > Actions に保存します。

  5. 5

    config.yml を自分の専門領域に合わせて編集

    PubMed クエリ・除外誌・送信時刻 (cron) を書き換えれば完了。 翌朝から Gmail に daily digest が届きます。

Safety カバー 7 テーマ

digest が拾う「臨床で AI を使う側が守るべき」論点の軸。

Prompt injection

患者入力や貼付文書経由で指示が書き換わる攻撃面。

PHI leak

外部モデルに個人識別情報が流出するリスクと対処。

Model drift

導入後に性能が徐々に劣化する現象と監視法。

Automation bias

AI 出力を過信して臨床判断が鈍る行動バイアス。

Adversarial inputs

画像・テキストへの微細改変で誤判定を誘発する攻撃。

Bias / fairness

学習データ由来の subgroup 格差と臨床影響。

Accountability

AI 誤判定が患者に及んだときの責任主体・監査証跡の残し方。
